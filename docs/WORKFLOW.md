# BABYMIZZ güvenli geliştirme akışı

1. Canlı MAPEDO temasını değiştirmeyin. Önce Shopify yönetim panelinden temanın kopyasını alın.
2. Mevcut temanın ZIP yedeğini indirin; mağaza sırlarını GitHub'a yüklemeyin.
3. Bu depo yalnızca geliştirme kaynaklarını tutar; ilk aşamada tam Shopify teması içermez.
4. Yeni değişiklikler `develop/babymizz-theme` dalında yapılır, kod gözden geçirilir.
5. Shopify tema kopyasında test edin: mobil 375/390 px, masaüstü, varyant, sepet, kapıda ödeme, performans ve erişilebilirlik.
6. Canlı yayınlama yalnızca açık onayla yapılır. Otomatik deploy kurulmaz.

## Önemli

Bu GitHub deposu herkese açıktır. Tema dosyalarının gizli tutulması isteniyorsa depo ayarlarından Private seçilmelidir.

## Sonraki adım

Mevcut MAPEDO tema ZIP'i veya kaynak kodunu geliştirme dalına güvenli olarak içe aktarmadan, bu depodaki bileşeni tam çalışan Shopify mağazası olarak kullanamazsınız.
