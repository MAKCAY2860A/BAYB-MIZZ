# BAYB-MIZZ Shopify Theme

Bu depo MAPEDO / BABYMIZZ Shopify tema gelistirmesi icindir.

- `main`: Baslangic referansi. Dogrudan tema gelistirmesi yapilmaz.
- `develop/babymizz-theme`: Tema gelistirme dosyalari.
- Canli Shopify temasi otomatik olarak degistirilmez.
- Magaza erisim anahtarlari, musteri verileri ve gizli bilgiler bu depoya eklenmez.

**Not:** Bu depo su anda herkese aciktir. Shopify tema kodu yayinlanmadan once gizlilik ayarlarini kontrol edin.
